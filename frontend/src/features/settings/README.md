# settings：空间信息设置

## 职责

承载协作空间设置导航和基本信息页。管理员可按版本修改名称，同步更新租户名称；slug 保持不变。成员与计费页面由各自功能模块负责。

不负责成员权限实现或空间归档。

## 文件

| 文件 | 说明 |
| --- | --- |
| `settings-layout.tsx` | 设置页导航和子路由容器 |
| `general-settings-page.tsx` | 空间名称编辑及只读 slug |
| `*.test.tsx` | 导航、管理员编辑与普通成员只读测试 |

## 依赖与不变量

依赖 `features/spaces`、路由和 UI 组件；由应用路由消费。服务端仍校验角色与版本，界面的禁用状态不构成授权。

## 测试

MSW 模拟改名接口并验证普通成员无法提交编辑。
